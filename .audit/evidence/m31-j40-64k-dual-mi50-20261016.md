# Guarded 64K J=40 run on both MI50s

## Result

Both cards ran the same guarded 65,536-token prefill concurrently with the
Q4_K MMQ J=40 option enabled. GPU2 completed one sample in 380.861 seconds,
or 172.073 prompt tokens/s. GPU0 exited unsuccessfully after its run warned
at 80 C; its stop reason and final temperature are still in the remote run
metadata and have not yet been retrieved.

| GPU | PCI BDF | Result | Prompt time | Throughput |

| GPU0 | `0000:04:00.0` | Did not complete; guard warning at 80 C | — | — |
| GPU2 | `0000:88:00.0` | Completed, one sample | 380.861 s | 172.073 tok/s |

The 64K execution is now demonstrated on GPU2 under the 180 W cap. This is
not yet a performance win claim: there is no 64K default-route control, and
the test has only one sample. Both logs emitted the 80 C warning. Keep the
thermal guard enabled for follow-up runs.
