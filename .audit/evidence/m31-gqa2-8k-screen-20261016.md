# Q8 dot4 GQA2 full-model 8K screen

## Result

The pushed 32-cell Q8 dot4 schedule completed an 8K full-model prefill, but
was slower than default attention in this one-sample screen:

| Path | Wall time | Prompt throughput | Start junction | Sampled peak |
| --- | ---: | ---: | ---: | ---: |
| Default | 33.836 s | 242.111 tok/s | 31 C | 80 C |
| Q8 dot4 prepack | 36.127 s | 226.758 tok/s | 38 C | 79 C |

The candidate took 6.8% longer and delivered 6.3% lower throughput. This is a
directional result, not a performance qualification: one sample per path, with
different starting temperatures. The quiet `llama-bench` logs do not print the
attention dispatch; the candidate runner set
`GGML_CUDA_FA_Q8_DOT4_PREPACK=1`, and the focused operator test on this binary
confirmed that the GQA6 dot4 dispatch is selected and passes.
