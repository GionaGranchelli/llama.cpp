# GQA2 dot4 2K profiled full-model screen

Date: 2026-10-16 (UTC)

## Result

One guarded default/candidate pair completed on GPU0 under ROCProfiler. The
default 2,048-token prefill took 8.355581187 s (245.106 tok/s); the dot4
candidate took 8.615886177 s (237.700 tok/s), 3.12% slower by wall time in
this single pair. This is a diagnostic screen, not a repeatable performance
verdict. Start temperatures differed (29 C default, 37 C candidate).

The remote ROCProfiler CSVs and logs were retrieved and aggregated. They confirm
the candidate executed the prepacked-Q route: 32 launches of
`flash_attn_tile<256,256,16,2,false,true,true>` plus 32 launches of
`ggml_cuda_fa_q8_prepack_kernel`. The default executed
`flash_attn_tile<256,256,16,2,false,false,false>`.

| Kernel group | Default | Dot4 candidate |
| --- | ---: | ---: |
| Flash attention tile | 109.199 ms / 32 calls | 226.571 ms / 32 calls |
| Query prepack | — | 8.254 ms / 32 calls |
| Flash attention combine | 11.071 ms / 32 calls | 11.180 ms / 32 calls |
| All summed GPU kernel durations | 7,936.120 ms | 8,188.180 ms |

The candidate tile takes 2.08 times as long as the default tile. The complete
attention-related kernel groups are about 2.0 times slower with dot4, while
quantized matrix multiplication remains the largest part of this 2K prefill
(about 6.9 s of 7.9 s summed GPU kernel time). The kernel-duration delta
(252 ms) is close to the 260 ms end-to-end delta. The candidate began warmer
(37 C versus 29 C), so this single pair remains a screen, not a causal or
repeatable verdict.
