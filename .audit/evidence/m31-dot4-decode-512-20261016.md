the default log contains none. This confirms graph reuse during both runs and
that the candidate dispatched, but the output does not correlate the dot4
prefill node with the reused graph instance. It is not yet proof that the
dot4-containing prefill graph itself was replayed.

This is a short smoke only. It does not establish 64K behavior, numerical
equivalence of generated tokens, or a stable performance difference.
